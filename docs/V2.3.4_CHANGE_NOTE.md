# v2.3.4 change note

- Keeps the original 10-case interval matrix as one benchmark flow.
- Retries common-cutoff sequential verification before giving up on the optimized route.
- Adds an exact endpoint-specific Gourdon fallback inside `gold1-interval` for cases where no common cutoff validates both endpoints.
- Records `gold1_execution_mode`, endpoint cutoff tuples, and common-cutoff metadata separately.
- Retries a matrix child once by default if it exits without producing `RESULT_JSON` (`MATRIX_CHILD_RETRIES` controls this).
- Replaces the old subtree-only legal-name helper with a package-wide release-stamping workflow that regenerates provenance and both manifests.

The endpoint-specific fallback is a correctness/scope extension, not evidence that the paired-D optimization wins at those scales. Performance claims still require a fresh validated run on the target machine.
